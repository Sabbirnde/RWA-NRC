# Proof of Concept Limitations & Assumptions

## Disclosures

- **PoC Scope**: Firecrawl and Mock RWA Provider data are reference data inputs for research and demonstration purposes. Firecrawl is not an authoritative financial oracle network.
- **Attestation Signer**: The EIP-712 attestation signer is centralized for the PoC. A production system would replace this with a decentralized oracle network / multi-sig consensus.
- **Legal Rights**: This PoC demonstrates smart contract mechanics and T+0 claim transfers. No off-chain legal agreement or bank custody integration is implied.
- **Audit**: Contracts are built for architecture demonstration on EVM testnets and have not undergone a formal security audit.
